# College Complaint & Issue Tracker

## Project Name
College Complaint & Issue Tracker

## Tech Stack
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- SQLite

## About the Project
The College Complaint & Issue Tracker is a web application that allows students to raise and track complaints. It provides a simple interface for submitting complaints and viewing their current status.

## Features
- Login using College ID
- Raise a new complaint
- View all complaints
- Complaint status (Open, In Progress, Resolved)
- Complaint category
- Search and filter complaints
- Stores complaints in SQLite database

## How to Use
1. Open the website.
2. Enter your College ID and login.
3. View all existing complaints on the Home page.
4. Click **Raise Complaint**.
5. Enter the complaint details and submit.
6. The complaint is saved in the database and displayed on the Home page.
